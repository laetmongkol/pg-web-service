# PG Solution — corporate website

A single-page site (TH/EN) over a 3D PG tower at night. Sections: Hero, About PG, Services, Why PG, connected systems, process, work and contact. Each section scrolls normally while the camera behind it glides to its own floor of the building.

It's a static page only — no backend, CMS or API.

```bash
pnpm install
pnpm dev        # http://localhost:3008
```

## Structure

| Path | Contents |
|---|---|
| `src/messages/{th,en}.json` | All copy on the page (from the PG Solution corporate website PDF) |
| `src/app/[locale]/page.tsx` | The one page: Navbar → TowerStage → 8 chapters → Footer |
| `src/features/story/` | Each chapter's content (HTML over the 3D) |
| `src/features/tower/` | The 3D scene (R3F), the blue-hour-to-night sky, scroll → camera, moving cars, the section rail, and the per-section objects on the right (`section-props.tsx`) |
| `src/app/globals.css` | Tokens from the design system v1.1 (Ink / Ivory / Coral / Stone / Muted / Rust) |
| `public/models/pg-tower-v6.glb` | The 3D model (Draco) exported from `design/3d/pg-tower.blend` |

## Editing the 3D

The model is generated by a script (`design/3d/build_tower.py`). Don't hand-edit it in Blender, or the next run will overwrite your changes.

```bash
blender -b design/3d/pg-tower.blend --python design/3d/build_tower.py
blender -b design/3d/pg-tower.blend --python design/3d/export_glb.py -- public/models/pg-tower-v6.glb
blender -b design/3d/pg-tower.blend --python design/3d/build_props.py
blender -b design/3d/pg-tower.blend --python design/3d/export_props.py -- public/models/pg-props-v1.glb
blender -b design/3d/pg-tower.blend --python design/3d/build_dungeon.py
blender -b design/3d/pg-tower.blend --python design/3d/export_dungeon.py -- public/models/pg-tower-v1b.glb
blender -b design/3d/pg-tower.blend --python design/3d/render_fallback_dungeon.py -- public/images/tower-fallback-v1b.webp
blender -b design/3d/pg-tower.blend --python design/3d/render_fallback.py -- public/images/tower-fallback.webp
```

- Adding or removing a section means editing both `build_tower.py` (the `scene(...)` list) and `SCENES` in `src/features/tower/scenes.ts` so the order matches.
- After changing the model, bump the GLB filename (e.g. `pg-tower-v7.glb`, `pg-props-v2.glb`) so browsers don't serve the old cached file.

## Notes
